Regra arquitetural

Centralizar mecanismos compartilhados não implica centralizar o domínio. O core não precisa conhecer a ontologia específica dos serviços que reutilizam seu runtime.

Execução reconstruível

Input State → Governed Transformation → Successor State

Cada execução material pode ser inspecionada como evento computacional identificado, não apenas como chamada de função.

Integração Reflexa

Praxis preserva e materializa transições; SisTer-Reflexa torna as trajetórias dessas transições cognoscíveis e devolve contexto para novas transformações.
